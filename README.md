# StudyBud
StudyBud er en mobilapp udviklet i React Native med Expo. Appens formål er at hjælpe studerende med at skabe et overblik over deres fag og opgaver. 

## Funktioner
Appen består af fem skærme:
- **Forside:** Brugeren kan indtaste sit navn og få en personlig velkomsthilsen.
--**Opgaver:** Brugeren kan se, tilføje og slette fag og opgaver.
--**Noter:**-- Brugeren kan oprette og slette huskesedler, gemme kontaktoplysninger på undervisere og tilføje eksamensdatoer.
--**Min profil:**-- Brugeren kan se en oversigt over fag og opgaver samt skifte mellem semestre. Hertil tage et profilbillede eller vælge et fra galleriet
--**Studietimer:**-- Brugeren kan vælge mellem 15, 25 og 45 minuter eller selv indtaste en valgt tid. Når tiden er gået vises en alert på telefonen. 

StudyBud bruger AsyncStorage til at gemme brugerens oplysninger lokalt på enheden. Det ville sige at brugeren kan åbne og lukke appen igen uden at miste sine informationer.

## Sådan køres projektet
1. Download projektet

2. Åbn projektmappen i en terminal

3. Installer afhænighederne:
    npm instal

4. Start Expo
    npx expo start

5. Åben appen med Expo Go på en telefon
